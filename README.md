# DALA

![DALA белгішесі](web/icons/Icon-192.png)

Құрлық, теңіз және дипломатия туралы Flutter/Dart стратегиясы. «Дала атласы» көрінісі тең ауданды, табиғи иілген ұяшықтарды қолданады. Android, iOS, Web және Windows бір код базасын қолданады.

Соңғы өзгерістер: [1.1.2 — ғимарат өндірісі және мод интерфейсі](docs/MOD_PRODUCTION_1.1.2.md), [1.1.1 — LAN клиентіндегі әрекетті қайтару](docs/LAN_UNDO_1.1.1.md), [1.1.0 — мод ғимараттары, радар және ұшақ](docs/MOD_TYPES_1.1.0.md), [карта айқындығы және дипломатиялық жерді қарау](docs/RENDERING_AND_TERRITORY_1.0.3.md), [модтар, карталар және өнімділік](docs/CONTENT_AND_PERFORMANCE_20260912.md), [жаңа дизайн](docs/DALA_DESIGN_20260912.md) және [ойын логикасының аудиті](docs/GAME_LOGIC_AUDIT_20260912.md).

## Қазір жұмыс істейтін мүмкіндіктер

Жаңа нұсқа: [1.2.0 — аралас жүріс кезегі, тұман, дипломатия, боттар және мод шаблондары](docs/RULES_1.2.0.md).

- әр жаңа шайқаста автоматты secure seed алатын, ал сценарийде қайталанатын
  көп-кезеңді арал генераторы (S–XL);
- 2–15 түс, 0–15 адамдық жергілікті hotseat/«Боттар шайқасы» және алты AI деңгейі;
- әскердің 4 деңгейі, біріктіру, қозғалу, шабуыл және қорғаныс;
- провинциялардың шабуылдан кейін автоматты бөлінуі/бірігуі;
- қала, шаруашылық, мұнара, қамал, салық, табыс және банкроттық;
- ағаш кесу сыйақысы және ағаштың раунд сайын таралуы;
- дипломатия, Slay ережесі, соғыс тұманы, флот, порт, теңіз қамалы және
  автоматты артиллерия;
- 50 тұрақты seed-пен қолмен іріктелген процедуралық кампания пресеті және сүзілетін ойыншы деңгейлері;
- жер/түс/нысан/әскер өңдейтін, жобаны SharedPreferences-ке сақтайтын және
  clipboard арқылы өз карта кодын экспорттайтын әрі пайдаланушы берген
  Antiyoy HD level code-ты импорттайтын карта редакторы;
- жеңіс шарты, толық ход соңындағы autosave және «Жалғастыру»;
- mouse/touch pan + pinch/wheel zoom;
- `.dalamod` арқылы жаңа ғимарат, радар, аэродром, құрлық әскері және ұшақ қосу;
- мод нысандарының бағасын, табысын, шығынын, қорғанысын, қозғалысын, көруін және PNG суретін баптау;
- `mods/` және `maps/` кітапханасы, `.dalamap` карталары, LAN-да кәдімгі/мод режимі.

## Архитектура

- `lib/src/game/` — Flutter-ға тәуелсіз state, generator, rules engine және AI;
- `lib/src/ui/` — экрандар мен бір canvas-тағы hex renderer;
- `lib/src/modding/` — пакет тексеру, файл импорты/экспорты және контент кітапханасы;
- `lib/src/persistence/` — versioned autosave, баптау және редактор жобасы;
- `assets/mods/` — bundled модтар.

UI әр hex-ті жеке widget қылмайды. Бүкіл карта бір `CustomPainter` canvas-ына салынады, zoom/pan compositor деңгейінде орындалады. Осы шешім XL картада да артық layout пен rebuild санын азайтады.

Мод жасау нұсқаулығы: [docs/MODDING.md](docs/MODDING.md).
