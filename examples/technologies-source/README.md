# Дала технологиялары

DALA 1.1.2 немесе кейінгі нұсқа қажет. Бұл үлгіде радар, аэродром және казарма бар.
Ұшақ аэродромның, барлаушы казарманың `production` тізімінде бапталады.
Үлгі модтың нұсқасы — 2, пакет форматы — 3. Толық нұсқаулық: `docs/MODDING.md`.

1. `mod.json` ішіндегі түрлерді өзгертіңіз. `my_dala_mod` атауын ауыстырсаңыз,
   барлық түрлердің ID префиксін де ауыстырыңыз.
2. Өз суретіңіз қажет болса, PNG файлын `sprites/my_dala_mod.radar.png`
   сияқты түрдің толық ID атауымен салыңыз. Суретті JSON-ға қоспаңыз.
3. `mod.json`, осы README және бар болса `sprites/` қалтасын ZIP-ке жинаңыз.
4. Архивті `.dalamod`, `.dalamod.zip` немесе `.zip` ретінде импорттаңыз.
5. Модты қосып, жаңа ойын бастаңыз. Провинция → Құрылыс арқылы ғимарат салыңыз.
   Аэродром → Әскер арқылы ұшақ шығарылады; казарма барлаушы шығарады.
   Әскер келесі өз жүрісінде дайын болады.

32 ғимарат түріне дейін, әр ғимаратта 32 өнім түріне дейін қолдау бар.
Өнімдер ғимарат лимитіне қосылмайды. Бұл анықтамалар санына қатысты;
картадағы ғимарат көшірмелерінің саны ақша мен бос орынға байланысты.

LAN үшін осы пакетті әр ойыншы бөлек импорттауы керек.
