# Giant-map, replay and compact-UI recovery — 2026-09-03

## Findings and changes

### High: neutral captures could keep the old terrain colour (fixed, reproduced)

Reproduction: giant map, 15 human colours, one starting province, no trees,
seed 20260903; buy a level-one unit onto an adjacent neutral tile. The game state
changed ownership from -1 to 0, but the cached terrain signature did not change.
On the Dart VM, `(-1).hashCode == 0.hashCode`. The renderer's signature passed the
unadjusted owner into `Object.hash`, so this common capture collided reliably.

Owner values now use the nonnegative `owner + 1` domain in terrain/unit/replay
signatures. `test/capture_repaint_test.dart` exercises the real controller and
checks both invalidation and the actual painted owner-colour pixel. It failed
before the fix and passes afterward. This is a confirmed defect, not a guessed
cache-clearing workaround.

### High: phone startup exit with the maximum settings (not yet verified fixed)

The connected Redmi 2201117TG / `8603e81` exit history included foreground SIGKILL
events. It did not establish whether Android killed the process for memory,
watchdog, or another reason. Do not label this a proven OOM or claim zero stalls.

The map generator repeatedly sorted the entire coast and recomputed whole-map
land/water components for each candidate cell. Coast trimming now maintains an
ordered frontier, updates only adjacent priorities, and checks connectivity
around the candidate. Existing map topology/capacity tests still pass.

Desktop debug timing for the same giant seed, one starting province: about
7.0–7.8 seconds before, 3.39 seconds after. Cumulative stage timings in
`build/generation-frontier-check.log`: land2550ms, coast2630ms, water2938ms,
provinces3389ms. These are desktop generation measurements, NOT phone FPS or
touch-latency measurements. The exact 15-colour / 100% forest / 45-province
configuration also generates and completes an AI round in regression tests.

The isolated Android profile package installation was rejected with
`INSTALL_FAILED_USER_RESTRICTED`. No fresh native benchmark ran and the main
phone app and saves were not replaced or cleared in this turn. User permission
on the phone is still needed before native verification can proceed.

### High: replay skipped opening and hidden AI turns (fixed, tested)

The old recorder kept only the last 220 action snapshots. A long turn evicted
the start of the match. Recording during widget rebuilds also coalesced fast
turns; fog intentionally suppressed intermediate AI UI notifications.

Replay now keeps the opening position and one frame at each player-turn
boundary, including the final victory boundary. It stores compact JSON patches
with a full checkpoint every 32 turns, decoded lazily when displayed. It does
not retain a full object graph per action or drop the early turns. A separate
controller turn-boundary notifier records concealed AI turns without publishing
those hidden moves to the UI. Tests cover 260 turns, 250 actions within one turn,
independent random access, and fog-hidden AI turns.

### Medium: oversized diplomacy and menu typography (changed, visually checked)

- Diplomacy/inbox shell uses half the actual available screen height, not 74%.
- Country rows, titles, menus, editor exit choices and statistics use smaller
  type and spacing. Primary relation actions appear before lengthy explanations.
- Exchange/letter contents use one scrolling surface; all three short term
  editors remain reachable. Only one term picker expands at a time.
- Letter conditions precede the longer rationale; accept/reject controls remain
  fixed at the bottom. Widget flows cover 320x720, 390x844 and 1280x720.
- Removed the editor's extra outer black rectangle only. Hex borders, world
  dimensions, pan/zoom limits and editable cells remain unchanged.

### Medium: diplomacy valuation and impossible selections (changed, tested)

- A bot no longer values a single transferred capital as the seller's entire
  province. The town's recoverable economic value is bounded; a capital-for-$100
  exploit is rejected in the fixture while a genuine gift remains useful.
- Strong humans receive material-concession friendship candidates, not a bare
  friendship plea. Difficulty-scaled contact gaps are shorter; legal and utility
  checks still gate offers. This is heuristic AI, not a claim of human-level play.
- Type pickers hide unavailable relations, incompatible transition mixes,
  impossible war targets and same-giver duplicate subsidies. Final amount,
  ownership, duration and stale-state validation still happens on submission.
- Military treaties last 1–20 rounds (12 by default). A live war/peace conference
  holds expiry until obligations settle; transit alone does not hold it forever.
  Expiry returns stranded troops and leaves a six-round friendship buffer.
- Existing undated military treaties migrate to 12 rounds. LAN protocol is now
  **4**; host and clients must use matching builds. Save schema remains readable.
