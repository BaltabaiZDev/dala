# DALA тілдері

**Баптаулар → Тіл**: іздеуі бар 26 тілдік тізім. Қазақша сақталды және
[классикалық Antiyoy-дың ресми 25 тілі](https://github.com/yiotro/Antiyoy/blob/master/assets/languages.xml)
қамтылды: ағылшын, орыс, украин, неміс, чех, француз, поляк, итальян, испан,
словак, қытай (жеңілдетілген), түрік, болгар, португал (Бразилия), нидерланд,
венгр, беларусь, индонезия, грек, норвег (букмол), серб, литва, хорват,
каталан және латыш. Тілді өз атауы, ағылшынша атауы немесе коды арқылы іздеуге болады.
Таңдау құрылғыда сақталады,
мәзірлерді ауыстырғанда және ойын қайта ашылғанда қолданылады. Материал
диалогтарының жүйелік мәтіндері де таңдалған тілде көрсетіледі.

Мәзір, мод кітапханасы, LAN, редактор, ойын HUD-ы, дипломатия батырмалары мен
ойын нұсқаулары ортақ каталог арқылы аударылады. Карта/мод атауы, мод авторының
сипаттамасы және ойыншылар жазған хаттар бастапқы мәтінін сақтайды.
Сақтау мен LAN деректері тілге тәуелсіз: тіл мод хэшін немесе ережелерді өзгертпейді.

Каталог: `lib/src/l10n/catalog.txt`. Әр жолда `қазақша|орысша|ағылшынша`.
Қалған 23 тіл `assets/l10n/*.json` файлдарында. Олар машина аудармасынан
басталды; қысқа ойын басқару мәтіндері мен анық табылған қателер түзетілді.
Барлық тілді ана тілінде сөйлейтін маман толық тексерген жоқ. Өзгерістер
`tool/review_catalog.py` ішінде қайталанып қолданылатын түзетулермен сақталады.
Ойын аударма қызметіне жүгінбейді: тек таңдалған бір каталог жадқа жүктеледі.
Қытайша интерфейс үшін OFL Noto Sans SC негізіндегі шағын қаріп бірге беріледі.
`{0}`, `{1}` сияқты орынбасарлар динамикалық мәндерді сақтайды; `\n` — жаңа жол.
Мәтін каталогта табылмаса, бастапқы мәтіні көрсетіледі. Бұл ескі сақтаулардағы
оқиға мәтіндері мен мод авторлары берген мәтіндерді жоғалтпайды.

Өзгерістен кейін:

```powershell
python tool/build_translations.py
python tool/translate_catalog.py  # тек каталог жаңартқанда, интернет қажет
python tool/review_catalog.py
python tool/subset_chinese_font.py  # build/NotoSansSC-full.ttf және fontTools қажет
dart format lib/src/l10n/catalog.dart
flutter test test/localization_test.dart test/language_picker_test.dart
```

`GameText` мәтінді көрсету кезінде аударады. Қолданушы мәтіні үшін
`translate: false` қойылады. Tooltip/semantics үшін `context.tr(...)` қолданылады.
Ойын логикасы мен желілік хабарламаларды аударылған мәтінге тәуелді етпеңіз.
